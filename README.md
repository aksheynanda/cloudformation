# cloudformation
CloudFormation template to create initial codepipeline

This repo is used to save all cloudformation template used to create All Code build and code pipeline used in project

CFT-docerimagepipeline.yaml :- used to create code build and pipeline to create image for application ADD and save it to ECR
CFT-docerimagepipelinelatest.yaml :- used to create code build and pipeline to create image for application latest and save it to ECR
CFT-docerimagepipelinenginix.yaml :- used to create code build and pipeline to create image for application nginix and save it to ECR
Clouformation.yml:- used to deploy terraform code
app-add-cft.yml:- used to deploy application to eks
